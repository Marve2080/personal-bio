# Personal Bio Page

A simple, responsive personal bio page built with HTML and CSS. It presents a short profile, a list of skills, contact details, and social links in a clean, centered card layout.

# Features
Centered profile card with a circular profile photo\
Short bio with name, role, and tagline\
Skills section (HTML, CSS, JavaScript, React)\
Contact section with email, phone, and location\
Footer with social media links\
Responsive design that adapts to smaller screens (max-width: 680px)\

# Getting Started
Run locally
1. Clone the repository:

```bash
git clone https://github.com/your-username/your-repo-name.git
```
2. Navigate into the project folder:

```bash
cd your-repo-name
```
Open index.html in your browser. No build step or dependencies are needed.
# Customization
Profile photo: replace assets/src/profile.png with your own image (keep the same filename or update the src in index.html). \
Name, role, and bio: edit the content inside the .about section in index.html. \
Skills: add or remove <li> items in the .skills list. \
Contact details: update the email, phone, and location in the .contact list. \
Social links: replace the # in the footer links with your actual LinkedIn and Twitter profile URLs.\
Styling: tweak colors, fonts, and sizes in index.css. \
Responsive Behavior

On screens 680px wide or smaller, the profile image shrinks and the heading size and color are adjusted so the page remains readable on mobile devices.
